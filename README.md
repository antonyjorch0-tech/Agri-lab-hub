# AgriLab Hub

Run locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy free: push this folder to a GitHub repo, then at share.streamlit.io choose
"New app", pick the repo, set the main file to app.py, and deploy.

Optional: if OpenAlex asks for a key, add OPENALEX_API_KEY = "your-key" under
App settings > Secrets on Streamlit Community Cloud.
